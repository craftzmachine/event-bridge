# Proposal Studio

Build a tailored proposal, review it exactly as the client will see it, and send it as a private web page, a PDF or an Excel workbook.

[Screenshot: Studio home]

## The Studio home
- **New proposal** — start blank.
- **Start from a package** — start from a saved set of elements.
- **From Excel** — convert an existing estimate spreadsheet (see below).
- Your proposals, with search, status and the Grand Total. Open, **Duplicate** or delete each one.
- A summary of what was sent and accepted this month.
- **Back up all** and **Import** (see [Getting started](01-getting-started.md#backing-up-and-moving-to-another-device)).

## Building a proposal: the four steps

### 1. Client & event
- Client name, mobile, email.
- **Event dates** — press **+ Add date** for multi-day celebrations. Dates are kept in order and shown together ("12th, 14th & 15th February 2027").
- **Venue** — start typing to pick from the Venue Directory. If the guest count is more than the venue's largest space holds, you'll see a warning.
- **Guests** and **budget** (the budget is for your team only).
- **Functions** — add Haldi, Mehendi, Sangeet, Muhurtham, Reception… each with its own date. Elements can then be placed under a function, and the proposal shows a subtotal per function.

### 2. Occasion
Pick the **event type** (Wedding, Engagement, Reception…) and **ceremony style** (Hindu, Christian, Muslim…). This decides which catalogue elements are suggested.

### 3. Elements
Add items from your catalogue, grouped by category (décor, catering, photography…). For each item:
- **Qty** and **rate**. Leave the rate as **as per actuals** when there's no fixed price.
- **Follow the guest count** — sets the quantity from the guests (for example 1 plate per guest, 1 chair per guest). Typing a quantity yourself turns this off.
- **Notes** shown to the client.
- **Upgrades** — for each: *No*, *Offer* (listed under Additional Options for the family to choose) or *Include* (added to the price).
- **Additional option** — list the whole item separately, not in the total.
- **Function** — which function the item belongs to.
- **Cost** (internal) — what it costs you per unit. Used for margin; never shown to the client.

On phones, your selection sits in a drawer above the step bar.

### 4. Review
- The branded **preview**, exactly as the client will see it.
- **Co-ordination %** and an optional **round-off** of the Grand Total.
- Edit the **notes** and **terms**.
- Side column:
  - **Budget bar** — when over budget, suggests cheaper swaps from the same category.
  - **Margin** — total cost against price, with a warning below your minimum margin.
  - **Payments** — the schedule (by default 70% on booking, 30% a week before the first event) and payments received, with receipts.
  - **Save as a package**.
  - **Status** — Draft, Sent, Accepted, Lost.

## Sending it
On the Review step, **Deliver**:
- **Share with client → web page**: a private, password-protected page of the proposal. Pick a theme in the full-screen preview first.
- **Share with client → PDF**: the PDF as a protected, view-only link.
- **Download PDF** or **Export to Excel** to send the file yourself (the ▾ next to the export button switches between them).

When you share:
1. Choose a password (or **Generate**) and how long the link lasts (7, 30 or 90 days).
2. Copy the link and the password. **Send them separately** — for example the link by email and the password by WhatsApp.
3. A draft is marked **Sent** automatically.
4. The family can **approve** or **ask for changes** with a comment. Their answer appears on the Studio home and the Dashboard.

## Create a proposal from Excel
1. **From Excel** on the Studio home, then choose an `.xlsx` estimate.
2. Event Bridge reads the client, dates, sections and line items, and tells you which cell each value came from.
3. Anything missing, unclear or contradictory becomes a **question** — it never guesses. Answer each one, choose **decide later**, or **skip** a row.
4. **Create** saves it as a new proposal.

Old `.xls` files aren't supported; open them in Excel and save as `.xlsx` first.

## Packages
A package is a saved starting point: elements, quantities, functions. Save one from the Review step; start one from **Start from a package**. Your admin can also ship team packages for everyone.

## Tips
- Drafts save as you type. The **quotation reference** (for example `20262711-KQR`) is created automatically and can't be edited.
- **Duplicate** to start a similar proposal; the copy starts as a draft with a new reference, and its checklist and answers are cleared.
- Additional options, Offer upgrades and as-per-actuals items are **never** added to the Grand Total.
- GST is shown as a reference figure; the Grand Total is before GST.

## Common questions
**Can the client see our costs or margin?** No. Costs are removed from every PDF, Excel file, web page and portal.

**I changed the venue's guest count and the quantities changed.** Items set to *Follow the guest count* update with the guests. Type a quantity to fix it.

**Why can't I edit the reference?** It must stay unique on your device so files and receipts can be traced back.
