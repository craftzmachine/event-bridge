# Visualize Proposal

Share any PDF or Excel proposal — even one made outside Event Bridge — as a private, password-protected, view-only page.

## Sharing a file
1. Drop in a **PDF** or **.xlsx** file (up to 4 MB; PDFs up to 30 pages).
2. Enter the client's name and a title.
3. Choose a password (or **Generate**) and how long the link lasts: **7, 30 or 90 days**.
4. **Create private link** → copy the link and the password, and send them separately.

## What the client sees
- A PDF as watermarked page images; an Excel file as a values-only grid (no formulas). They never receive your original file.
- **Approve** or **Ask for changes** with a comment.

## Following up
The list shows each link's views, the client's answer and when it expires. **Revoke** ends access immediately.

## How protected is it?
- The password is checked on the server; wrong, ended and revoked links all show the same message.
- Pages are watermarked, and common screenshot shortcuts blank the page.
- **Screenshots can't be fully prevented** by any website — a phone camera or a phone's own screenshot still works. Treat it as "discourages copying", not "impossible to copy".

## Tip
For proposals made in Proposal Studio, the Review step's **Share with client** does all of this in one go.
