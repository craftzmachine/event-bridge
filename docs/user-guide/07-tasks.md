# Tasks

The team's own tasks and every wedding's checklist, in one place.

## Adding a team task
**Add a task** → title, due date, who's doing it, an optional event, priority and notes.

## Finding tasks
- Filter by **Mine**, **Whole team** or **Family's**, and by event.
- Views:
  - **List** — Overdue, This week, Later, Done
  - **Board** — To do, Doing, Done
  - **Calendar** — by due date

## Checklists here and in the workspace
Every active wedding's checklist tasks appear here. Tick one here and it's ticked in the wedding's workspace too, and the other way round.

## Tips
- Overdue tasks show on the Dashboard under **Needs attention**.
- Lost weddings' checklists are left out.
